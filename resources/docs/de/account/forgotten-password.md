:::steps
1. Wählen Sie auf der Anmeldeseite **Passwort vergessen?** und geben Sie die E-Mail-Adresse Ihres Kontos ein.

2. Öffnen Sie die eintreffende Nachricht und folgen Sie dem Link darin. Er funktioniert einmal und nur für begrenzte Zeit.

3. Wählen Sie ein neues Passwort, wiederholen Sie es und drücken Sie **Passwort zurücksetzen**. Sie können sich damit sofort anmelden.
:::

## Es kommt keine Nachricht

Prüfen Sie zuerst den Spam-Ordner. Die Nachricht geht nur an eine Adresse, zu der ein Konto gehört, und die Seite sagt in beiden Fällen dasselbe — ein Tippfehler in der Adresse sieht also genauso aus wie eine fehlende Nachricht. Fordern Sie einen neuen Link an, wenn der erste abgelaufen ist.
