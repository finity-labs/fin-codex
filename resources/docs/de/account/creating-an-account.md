Tragen Sie Ihren Namen, Ihre E-Mail-Adresse und ein Passwort ein, wiederholen Sie das Passwort und drücken Sie **Registrieren**. Sie sind sofort angemeldet.

## Ihr Passwort

Wählen Sie ein Passwort, das Sie nirgends sonst verwenden. Eine längere Wortfolge schlägt ein kurzes, kompliziertes Passwort. In beiden Feldern muss es Buchstabe für Buchstabe übereinstimmen.

## E-Mail-Adresse bestätigen

Manche Anwendungen verlangen, dass Sie Ihre E-Mail-Adresse bestätigen, bevor es weitergeht. An die angegebene Adresse kommt eine Nachricht mit einem Link; öffnen Sie ihn, und es ist erledigt. Kommt nichts an, prüfen Sie den Spam-Ordner und fordern Sie auf der Bestätigungsseite eine neue Nachricht an.
